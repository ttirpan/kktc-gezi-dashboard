# KKTC Gezi Dashboard

Telefon ve masaüstünde çalışacak basit bir Vite + React dashboard projesi.

Bu sürümde konum kartları ve rota özetleri tıklanabilir Google Maps linkleri içerir.

## Kurulum

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub'a yükleme

1. Bu klasörü bir GitHub reposuna at.
2. Vercel veya Netlify ile bağla.
3. Deploy et.
